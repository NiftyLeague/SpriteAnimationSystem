# Sprite Animation System

Degen sprite rasterization and animation tooling for Unity. Licensed under
Apache-2.0.

## Excluded commercial plugins

Two Unity Asset Store products are **not** redistributed in this repository
because their licenses prohibit public redistribution:

- `Assets/Plugins/Beebyte/` — Beebyte Obfuscator
- `Assets/Plugins/AllIn1SpriteShader/` — All In 1 Sprite Shader

Game code has no compile-time dependency on either; materials authored
against the AllIn1 shaders will render magenta until the plugin is re-added
from your Asset Store library. `Assets/Scripts/AutoGenerated/Resources.cs`
keeps the shader-name constants for reference.
